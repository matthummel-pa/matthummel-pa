# WordPress plugin

Embed **Branchborne Gem Quest** with the `[git_blocks]` shortcode.

## Install

1. Copy this folder to `wp-content/plugins/git-blocks/`  
   or run `npm run pack:wp` from the repo root and upload the zip.
2. Activate **Branchborne Gem Quest**
3. Add `[git_blocks]` to a page

Keep `assets/js` and `assets/css` in sync with `../play/` (`npm run sync:plugin`).

See the [root README](../README.md) for attributes and contributing.
