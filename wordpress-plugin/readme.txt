Bejeweled-style tech gem quest with side quests and trophies — embed with [git_blocks].

== Description ==

Branchborne Gem Quest is a canvas match-3 RPG with pathway classes, live side quests, and a trophy case. Drop it on any page with `[git_blocks]`.

Home: https://github.com/matthummel-pa/branchborne-gem-quest-game

== Installation ==

1. Upload the `git-blocks` folder to `/wp-content/plugins/`
2. Activate **Branchborne Gem Quest**
3. Place `[git_blocks]` on a page
