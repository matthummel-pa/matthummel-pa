Embeddable tetris-style Git Blocks cabinet for portfolio and demo pages.

== Description ==

Git Blocks is a small canvas game you can drop into any page with `[git_blocks]`.

Includes Customize (backgrounds, music, controls) and Share.

== Installation ==

1. Upload the `git-blocks` folder to `/wp-content/plugins/`
2. Activate the plugin
3. Place `[git_blocks]` on a page
