## Facebook

I built a tiny browser game on my GitHub profile — with Cursor Cloud agents — mostly for fun.

Git Blocks started as a Tetris-style “commit cabinet.” After a day of prompting, testing, and merging, it’s a Jewel Quest–style match-3:

• Swap web-dev logo gems (HTML, CSS, JS, React, PHP, WP…)
• Earn “lines of code”
• Learn from Intern → Senior Developer
• Get a web-dev fact every time you clear
• Pick a pathway class with a cartoon hero + class power

I wrote up how I prompted, what I’d prompt differently, the folder layout, and real code snippets the AI produced.

## LinkedIn (bonus — skill recommends within 2 days)

I spent a day prompting Cursor Cloud agents to reinvent a GitHub profile game.

Outcome: Git Blocks — a match-3 that teaches a path from Intern to Senior Developer, with lesson-tied cloud words and fact popups on every clear.

Takeaways for anyone using AI on real work:
1. Symptom-level prompts beat vibes.
2. Gate cosmetics until the core loop feels good.
3. Keep tests and PRs — agents write fast; you still own the merge.
